## Known risk areas

> Focus areas for M0.11.3 self-test — post hotfix/m5-smoke-bugs state (commit 55d573f)

1. **Phaser canvas render (RoomView)** — Bug fix #1: Phaser canvas was rendering 0px / not mounting. Now expects canvas element present with placeholder agent circles drawn. This is the primary high-risk verify point.
2. **WS transform error** — Bug fix #2: zod schema mismatch caused subscription failure (`WS transform error`). Expect NO console errors containing "transform" or "zod" or "subscription failed" post-fix.
3. **TodoWrite mock残存** — Bug fix #3: production build leaked `TodoWrite` mock. Expect NO references to mock in console or DOM post-fix.
4. **Sidebar wire (dead navigate)** — Bug fix #4: Sidebar navigation did not update panel overlay. Expect panel routes to switch correctly when sidebar links clicked.
5. **General console errors** — Any unhandled promise rejections, TypeError, ReferenceError in console constitute potential regressions.
6. **Empty state rendering** — Views with no live daemon data should show graceful empty states, not crash or show blank screens.
7. **Theme token propagation** — CSS variables from tokens.css (pop default) should be applied; Phaser scene reads `--bg`/`--surface`/`--primary` via `getComputedStyle`.

## Pass criteria

- All routes load without crash (no white screen of death, no React error boundary fallback)
- Phaser canvas element present at `/` (REQ-032)
- Zero `error`-level console messages that are not known/expected no-data warnings
- All panel routes overlay Room correctly (Room canvas still mounted behind panel)
- 0 high/medium severity findings (low/info are acceptable)
