# M0.19 QA Suite Gap Fill Phase 1 Implementation Plan

> **For agentic workers:** PM が `loom-developer` subagent を Task tool で dispatch して実行する。各 task の `planned_files` HTML comment + `// covers:` comment + Integrity check が contract。Steps は claude-loom lightweight 5-field 形式 (Goal / Files / Spec ref / Integrity check / Commit prefix)。

**Goal:** qa-suite.js 515 case のうち、priority-0 missing 14 件 + naming mismatch + impl_only 156 件を D1 厳密で full coverage 化し、Phase 1 gap-fill 完了状態に持っていく。

**Architecture:** `audit:qa-coverage` script を CI gate として導入し、`// covers: <case-id>` grep traceability を確立。既存 covered case (~110 件) には comment 注入、impl_only 156 件には Vitest test 追加、priority-0 missing 14 件には新規 test + 一部 impl 修正。N/A 24 件は `configs/qa-na-allowlist.txt` で例外承認。

**Tech Stack:** Vitest + Playwright + bash audit script + eslint (lint rule for OV-NO-ALERT/NO-PLACEHOLDER) + GitHub Actions

**Design spec:** `docs/design/2026-05-21-qa-suite-100pct/design.md`

**Branch:** `test/qa-suite-gap-fill-phase1`
