# M0.20 QA Suite UX/Edge Coverage Implementation Plan

> **For agentic workers:** PM が `loom-developer` subagent を Task tool で dispatch して実行する。各 task の `planned_files` HTML comment + `// covers:` comment + Integrity check が contract。Steps は claude-loom lightweight 5-field 形式 (Goal / Files / Spec ref / Integrity check / Commit prefix)。

**Goal:** qa-suite.js 479 case のうち、cross-cutting 110 件 (UX/EG/CH/MS/NT/SEC/IN/PH/AR) + 残 missing 75 件を D1 厳密で full coverage 化し、QA Test Matrix.html walkthrough で全 479 case marked pass、**Phase 2 entry gate 通過**状態に持っていく。

**Architecture:** Cross-cutting case は実装本体への横断 audit を伴う。各 section ごとに pattern test (UX/EG) / visual diversity test (CH) / milestone feature audit (MS) / 個別機能 test (NT/SEC/IN/PH/AR) を分担。残 missing 75 件は section 内の機能 missing で、impl 追加 + test 追加の両輪。M0.19 で構築した audit script CI gate を引き継ぎ、closure 時に QA Test Matrix.html browser walkthrough を Phase boundary verification として実施。

**Tech Stack:** Vitest + Playwright (UI 振る舞い test + visual regression) + browser interactive walkthrough (manual) + JSON state export

**Design spec:** `docs/design/2026-05-21-qa-suite-100pct/design.md`

**Branch:** `test/qa-suite-ux-edge-coverage`

**Prerequisite:** M0.19 `m0.19-complete` tag 設置済 (audit script CI gate + N/A allowlist + naming mismatch resolved 状態)
