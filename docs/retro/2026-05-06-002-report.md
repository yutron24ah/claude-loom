### F-USER-005 [pj / spec-drift-architectural / **CRITICAL** / structural]

**daemon production startup pipeline 破綻 (M0.X-startup-recovery 新 milestone 起票)**

M0.11.5 t3 「daemon が production mode で `:5757` で `ui/dist` serve」claim と reality:
- `daemon/dist/index.js` は **型 re-export module**、起動 entry でない
- 真の entry は `daemon/dist/server.js`
- `runMigrations()` が `resolve(_dirname, "./migrations")` で探す `daemon/dist/db/migrations/` directory が tsc では dist へ copy されない → crash
- `tsx` runtime (devDependency 限定) が production で resolve 不能

evidence (PM が直接 verify、本 retro session 中):
```
Failed to start daemon: Error: Can't find meta/_journal.json file
    at readMigrationFiles (drizzle-orm/.../migrator.ts:29:9)
    at runMigrations (daemon/dist/db/client.js:18:5)
    ...
```

**Apply (本 retro session 内 hotfix)**:
- daemon/package.json build script: `tsc && pnpm run build:migrations` で migrations bundle copy 追加 (commit 430924d)
- start script から `--import tsx` 除去 (compile 済 .js のみで起動可能)
- `tests/daemon_e2e_startup_test.sh` 新設 (commit fb1e7c1)、curl /health → HTTP 200 verify (E2E production startup test、再発防止 mechanism)
- 新 milestone **M0.X-startup-recovery** を PLAN.md に挿入 (Phase 2 entry 前必須 task として codify)
